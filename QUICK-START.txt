================================================
SPINDLE - WINDOWS
Quick Start Guide
================================================

END USERS (installer)
---------------------
1. Download Spindle-Setup from GitHub Releases
2. Run the installer
3. Launch Spindle
4. Complete the welcome wizard and click Sign in with Discogs

No SETUP.bat or SETUP_OAUTH.bat required for official builds.

DEVELOPERS (from source)
------------------------
STEP 1: SETUP (First Time Only)
Double-click: SETUP.bat

STEP 2: OAUTH (Dev builds only)
Double-click: SETUP_OAUTH.bat
(or set DISCOGS_CONSUMER_KEY/SECRET before release build)

STEP 3: RUN
Double-click: LaunchAutoSortGUI.bat

PRO LICENSE
-----------
Help → Activate Pro license, or Settings → Pro License.
Beta keys: python scripts/generate_license_key.py --email you@example.com

OUTPUT FILES
------------
  • vinyl_shelf_order.txt
  • vinyl_shelf_order.csv
  • vinyl_shelf_order.json (optional)

TROUBLESHOOTING
---------------
Sign-in not available (dev): Run SETUP_OAUTH.bat or use the installer build.
Free tier: 100 records shown/exported; upgrade to Pro for full collection.

See docs/SUPPORT.md and README-WINDOWS.md
